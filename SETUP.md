# DevIsola GitHub Profile — v3

A self-contained, GitHub-ready profile README package, with SVG artwork inspired by the visual language of [Chronicles of the Multiverse](https://github.com/DevIsola/mtg-history).

## Contents

- `README.md`: Profile layout, editorial copy, featured projects, current work, and technical stack
- `assets/hero-banner.svg`: Illustrated profile hero
- `assets/chronicles-feature.svg`: Featured project banner with the archive's headline stats
- `assets/divider.svg`: Ornamental section divider
- `assets/community-card.svg`: CommunityEvents project banner
- `assets/analysis-card.svg`: ENEB Project banner
- `assets/working-stack.svg`: Technical-stack panel

## Publish

1. Create a **public** GitHub repository at `https://github.com/new`, naming it **`DevIsola`** (identical to your GitHub username).
2. Upload **README.md** to the repository root.
3. Upload the entire **assets/** folder alongside it. Keep the filenames intact; the README links use relative paths.
4. Commit the files to the default branch. GitHub displays the README above your repositories on your profile.
5. Pin the `mtg-history` repository and whichever other repos you want to emphasize, using **Customize your pins** on your profile.

## Notes

- The archive art is **original SVG source**, visually inspired by the color palette, constellation detail, and portal motif of the Chronicles repository, not a copy of its original banner.
- Artwork is local SVG. The Chronicles screenshots are loaded from `mtg-history/docs/screenshots/`, so they stay current whenever that repo's Playwright workflow recaptures them. No badge generators, stats widgets, fonts or scripts are required.
- The stats in `chronicles-feature.svg` (10 chapters, 88 characters, 130 events, 118 relationships, 133 card printings) mirror the mtg-history README; update both together as the archive grows.
- Cards link to repositories and the featured project points to its live site.
- The in-development work is labeled as such; it does not imply public repositories or released products.
- To edit wording, modify `README.md`; to change visual labels, modify the corresponding SVG files.
